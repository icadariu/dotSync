# Security Policy

## Supported Versions

Only the [latest release](../../releases/latest) receives security fixes.

## Reporting a Vulnerability

**Do not open a public issue for security vulnerabilities.**

Report it privately through
[GitHub private vulnerability reporting](../../security/advisories/new)
(Security tab, "Report a vulnerability").

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested remediation (if any)

## Response SLA

| Severity | Initial response | Patch target |
|----------|-----------------|--------------|
| Critical | 24 hours        | 7 days       |
| High     | 48 hours        | 14 days      |
| Medium   | 5 business days | 30 days      |
| Low      | 10 business days| 90 days      |

## Disclosure Policy

We follow coordinated disclosure. Please allow us time to patch before
publishing details publicly.
